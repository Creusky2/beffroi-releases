# Beffroi — versions du launcher

Ce dépôt ne contient que les versions publiées du launcher Beffroi pour Windows.

- **Installer** : téléchargez le fichier `Beffroi-Launcher-Setup-<version>.exe` de la [dernière version](https://github.com/Creusky2/beffroi-releases/releases/latest).
- **Mises à jour** : le launcher vient chercher ici les nouvelles versions et les installe tout seul.

Windows affiche un avertissement au premier lancement, car l'installateur n'est pas signé : « Informations complémentaires », puis « Exécuter quand même ».

Un compte Minecraft (Java Edition) officiel est nécessaire pour jouer.
